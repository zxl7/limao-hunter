# 盘中信号升级：S 级题材怎么识别、情绪怎么传导

本次升级的核心，是把「盘中推送」从「什么都在报」改成「按题材影响力分级报」——只在你真正需要的时候、用你真正需要的信息提醒你。下面分三个部分说明：**信号分几级**、**板块强度怎么评分**、**情绪怎么在盘面里传导**。

---

## 一、信号分三级：S 级、苗头级、A 级

盘中异动不再一视同仁，按「对题材方向的判断力」分三级推送：

| 级别 | 含义 | 推送方式 |
|---|---|---|
| **S 级（红卡）** | 板块整体共振确认，题材要起爆 | 秒级即时推送 |
| **苗头级（紫卡）** | 板块刚启动，可能成为 S 级 | 秒级即时推送（每天每板块限 1 次） |
| **A 级（聚合卡）** | 次级信号，跟风/冲板/快讯等 | 每 15 分钟聚合推送一次 |

**关键区别**：以前所有异动都等 15 分钟汇总，等你看到可能已经晚了；现在 **S 级和苗头级秒级推送**——真正决定题材方向的信息不让你等。A 级信号（单股冲板、普通强势）仍然 15 分钟汇总一次，避免刷屏。

---

## 二、板块强度评分：五个条件，缺一不可

「S 级题材」不是某只股票暴涨就叫的，而是**整个板块整体行动**。系统用五个条件给板块评分（满分 5 分，≥4 分才确认为 S 级）：

1. **板块联动**：板块内 ≥3 只涨停（不是孤军奋战）
2. **容量中军**：大市值核心股动了（市值 ≥80 亿，且涨幅 ≥5% 或封板——光市值大没涨不算）
3. **板块广度**：板块内一半以上股票涨停（整体性，不是几只票凑数）
4. **大盘共振**：三大指数同向上涨 ≥1%（大盘配合，甚至带动大盘）
5. **封死叠加**：龙头一字板/秒封/封死（资金态度坚决）

**提前布局靠苗头级**：不等板块涨满，**板块刚启动**（涨停数开始增加 + 容量中军拉升 + 前排封板）就提示你「苗头」——等确认时再提示就晚了。每条提示还会告诉你：**这板块往上走（预判升级 S 级）还是往下走（预判降级）**，以及**哪只票是核心**（按成交/换手活跃度定位，活跃度越高的辨识度越高，容量中军不一定是最活跃的那只）。

---

## 三、情绪传导：盘面是一个整体，不是割裂的数字

整个 A 股盘面是一个**可传递、相互关联的整体情绪场**——消息影响板块，板块带动个股，个股又影响大盘，情绪在这些环节之间自然传递。系统把 12 个维度统一纳入同一套分析框架，让它们**互相印证**：

```
消息面（快讯/催化）→ 板块热度（涨停/梯队）→ 盘中强势（早鸟埋伏）→ 个股行情
→ 大盘情绪（12 因子打分）→ 选股/接力 → 竞价验证 → 收益反馈闭环
```

**具体怎么体现「整体」**：
- **消息→板块**：快讯点名的题材会进入盘后候选，盘中强势（未封板大涨）的股票会透传到次日的「早鸟埋伏」区——盘中发现的线索，盘后不丢
- **板块→大盘**：涨停数、涨跌家数、两市成交额、指数强度全部进入同一套情绪打分，互相验证。比如「涨停翻倍 + 普涨 + 放量」同时出现，才是真正的亢奋行情（而不是只看涨停数）
- **矛盾时以统一打分为准**：某个信号说退潮、但情绪分明确是亢奋 → 以整体打分为准，不让单一维度误判

**一个具体的打通**：以前「涨跌家数」只统计了上海市场约 2000 多只股票，现在覆盖沪深全市场约 5000 只——情绪温度计的读数更准了。所有卡片都会标注数据口径和截止时间，数字来源透明。
