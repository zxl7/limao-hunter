## 一、本期核心：盘中信号 S/A/B 三级分级体系

用户核心诉求「暴拉/涨停决定题材方向爆发」+「S级题材=整体性全军出动」落地为**三级信号分级**，替代旧版"所有异动一律进 15min 窗口缓冲"的平铺模式：

| 级别 | 信号 | 推送方式 | 时效 |
|---|---|---|---|
| **🔥 S 级** | 板块整体共振（共振评分 ≥4/5） | **秒级即时推**（红卡） | 实时 |
| **🌱 苗头级 pre-S** | 板块刚启动（前瞻评分 ≥4 或 中军拉升） | **秒级即时推**（紫卡·每天每板块限1次） | 实时 |
| **📊 A 级** | 冲板/强势/快讯/板块异动/未共振单股 | **15min 窗口聚合推**（降噪主体） | 窗口 |
| **⚡ 紧急** | 核按钮(≥3)/回流前兆 | 独立即时推（每天限频） | 实时 |

### 1.1 S 级 = 板块共振评分 `_resonance_score`（满分 5）

S 级不再是"单股暴拉"（用户原话：单股暴拉是小卡拉咪），而是**板块整体共振**：

| 要素 | 判定阈值 |
|---|---|
| ① 板块联动 | zt_count ≥ 3（板块多只涨停·全军出动） |
| ② 容量中军 | cap_yi ≥ 80 亿 **且动了**（涨幅 ≥5% 或封板——光市值大不动不算共振） |
| ③ 板块广度 | zt/total ≥ 50%（板块内过半涨停·整体性） |
| ④ 大盘共振 | 三指数均涨幅 ≥ 1%（大盘配合·甚至共振大盘） |
| ⑤ 封死叠加 | seal 含 一字/秒封/封死 |

**score ≥ 4 → S 级题材爆发卡（秒级即时推）**；score < 4 → 降 A 级入窗口聚合（涨停多≠S级，缺共振要素不刷屏）。

### 1.2 苗头级 pre-S = 前瞻共振评分 `_resonance_signal`（满分 5）

用户「不能等半个板块涨停才提示·那我买个得儿」——**板块刚启动就提示**，不等共振成熟：

| 要素 | 判定阈值 |
|---|---|
| ① 启动增量 | 本轮 zt > 上轮（对比 prev.json） |
| ② 容量中军 | cap ≥ 80 亿 **且动了** |
| ③ 扩散强度 | 增量 ≥2 或首现 3 只+（板块级扩散非单股） |
| ④ 封板节奏 | 一字/秒封/早封（资金坚决） |
| ⑤ 大盘共振 | 三指数均涨幅 ≥ 1% |

**score ≥ 4 → 「🌱 S级题材苗头」紫卡**；**⛔ 中军拉升独立触发**：容量中军 cap≥80 拉到 +5%~9.9% 且板块前排封板 ≥2 → 即使前瞻分<4 也按苗头推（中军拉升=资金进场强启动确认）。

### 1.3 等级迁移预测（看板块往上还是往下）

等级不是静态标签——每轮把 top5 板块 zt_count 记入 `sector_zt_series`（10 轮），判方向 + 预测：

| 当前等级 | 趋势方向 | 预判 |
|---|---|---|
| 🌱 苗头 | 📈 rising | 📈 预判升级 S 级 |
| 🌱 苗头 | 📉 falling | 📉 预判降级 |
| 🔥 S级 | 📉 falling | 📉 预判降级 A 级（共振瓦解·警惕退潮） |
| 🔥 S级 | 横盘+资金流出 | 📉 预判降级 |
| 📊 A级 | 📈 rising | 📈 预判升级 |

每张苗头/S级卡必含「📈/📉/➡️ 预判」行。

### 1.4 板块核心票定位 `_locate_core_stock`

用户「对比成交量/换手定位活跃度·活跃度越高辨识度越高」：板块内（leader+跟风票）按活跃度排序（leader 用成交额代理=流通市值×换手率、跟风票用换手率；涨幅>0 优先）→ **活跃度最高的票 = 辨识度最高的核心票**。S级/苗头卡渲染「🔑核心票」行——**容量中军 ≠ 最活跃核心票**（20cm 高换手跟风票辨识度更高，实证：医药海泰新光/PCB金禄电子）。

### 1.5 信号分级配套（频率与降噪）

- **早盘定时降频**：盘中猎手 0930/0935/0945 停用（保留 0925 开盘定调 + 0940 十分钟档），消除「严禁 5 分钟簇」规则漂移

- **事件→定时桥接**：复用 pulse_aggregator 15min 窗口缓冲（不重复建设）
