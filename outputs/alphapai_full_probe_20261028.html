七、边界与限制（实测或源码确认）

额度不可查：整个 CLI 没有剩余额度命令。要查额度只能走 alphapai-lite-mcp 连接器。 qa / agent / recall / da-query 是计费层，列表接口未见计费提示但未经官方确认。
recall 的 --no-cutoff 是空参数：文档自述 isCutOff=true/false 返回内容无差异。别指望拿更长原文。
三类纪要互不通用：meeting-minutes（平台聚合公开会议）、recording（自己上传）、 meeting-booking（会议机器人录制），roadshowId / taskId / msgId 不可混用。
agent 模式号有缺口：1,2,3,5,7,8,9,11,12,13,15 可用，4/6/10/14 未开放，不要猜用途。
加密 ID 会过期：公告、研报、点评的 announcementId / reportId / commentId 不可长期复用，每次都要先 list 再 detail。
