## 一、对用户质疑的判断：**成立，且重型地基应当砍掉**

用户原话：「我们是灵活的太空舰队，历史真的有必要吗」。

**我的判断：这句话对。** 三条理由：

| # | 理由 | 事实依据 |
|---|---|---|
| 1 | **战法错配** | 情绪核心战法的判据（辨识度 / 板块联动 / 封板质量 / 资金流向）**全是当日或近 3 日信息**；3.2 年市场日K库**服务不了它**——那是给「多因子 alpha 研究」用的 |
| 2 | **样本量错配** | 账户约 2 万、每天 1-2 票、**年均决策约 100 次**。拿 3 年市场历史做统计检验 → **统计力根本不够，只会拟合出噪声规律**（这正是过拟合的来源，不是解药） |
| 3 | **不可替代性错配** | **市场历史可以买**（腾讯日K 800 根，实测并发 16 路 **2.5 分钟**随时可抓）；**决策历史买不到**。稀缺的是后者，而**它已经在积累** |

**→ 定调：不建「研究所」，建「黑匣子」。**

```
太空舰队三件套          对应我们的系统            现状
─────────────────────────────────────────────────────────
🛰️ 雷达（实时感知）  ←  盘中脉冲/情绪/资金池      ✅ 强项
⬛ 黑匣子（决策史）  ←  zt_history+candidates+净值  ⚠️ 有，但漏
🏛️ 研究所（因子挖掘）←  3.2年市场库/分位标定      ❌ 不该建
📚 图书馆（全量存档）←  全市场分钟/长历史          ❌ 不该建
```

## 二、修订后的计划

### ❌ 撤销 / 降级

| 原项 | 处置 | 理由 |
|---|---|---|
| **P0 历史行情地基**（重建 3.2 年全市场日K） | **撤销·降级为「按需临时抓」** | 服务不了情绪核心战法；真有需要时 2.5 分钟即可现抓，**不必入库维护**（维护成本 + 诱导过拟合） |
| **P3 留出集封存 / 分层验证 / Sharpe≥0.5 门槛** | **削掉**（保留"负知识 + 一轮只改一个变量"） | 那套是**给「参数寻优」准备的防线**；我们 `learning.auto_apply` **默认关**、单次幅度上限 0.3、只做单参数小步 → **不做寻优，防线没有敌人** |
| **P4 阈值分位标定** | **不做** | 样本 23 天（原想用 1454 天）→ 分位标定**在统计上无意义**，会标定噪声。可保留"用现有 23 天**审计**一下 4.5/7 分落在哪个区间"，一次性、不入库 |

### ✅ 保留（不依赖历史·都是「当下」能力）

| 项 | 内容 | 成本 |
|---|---|---|
| **P1 情绪平滑 + 2日确认** | `gen_sentiment_summary.py` 现只有 `ma3`（3日窗）；补 **EMA(α=1/3) 平滑 + 连续2日确认** → 输出「待确认」中间态。开关 `ENABLE_PHASE_CONFIRM` | 小 |
| **P2-a 弱档否决** | 大盘弱势时**否决**梯队强度的正向阶段判定（防 2024-01 型「梯队强 + 大盘崩」误判主升） | 小 |
| **P2-b 交易日探针三级降级** | 现靠 akshare 日历（09-10 刚踩坑）；加「行情时间戳反证」层 | 小 |
| **P4 宽基过滤** | `sector_family.py` 加成员数上限（>600 视为风格标签不参与主线排名） | 小 |

### ➕ 新增（**这才是最该做的**·零历史抓取·堵漏）

| 项 | 问题（已核实） | 动作 | 价值 |
|---|---|---|---|
| **N1 口径单源** ✅已修 | ~~两个 `zt_history` 目录并存、字段不一致~~ → 实查：差异**仅 `intraday_points` 一个字段**，数据同源；但深挖出**两个更严重缺陷**（见下） | `RETAIN_DAYS` 5→20；新增 `ZT_HIST_DIR` 单一源并改 3 处引用；回填 24 天 | 供给≥需求、弱转强复活 |

> **我们发现的好东西，恰好都不需要那套重型地基。**

## 三、一句话结论

> **要的不是「地基」，是「别建错地基」。**
> 砍掉研究所（3.2 年市场库 / 分位标定 / 参数寻优防线），
> 修好黑匣子（口径单源 / 判断留档 / 已有数据归因），
> 保留雷达（情绪平滑 / 弱档否决 / 交易日探针）。

**如果只做一件：N1 口径单源**——因为它是**现存 bug 级风险**，且修复成本最低。
**如果做一批：N1+N2+N3**（全是堵漏，不动战法，零历史抓取）。
