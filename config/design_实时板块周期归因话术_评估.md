# 实时板块「周期归因话术」可行性评估

> 立项：2026-09-23 用户提「把实时板块模块里面向机器/术语化/数据化的输出，统一转译为普通用户看得懂的自然语言；
> 并引入**基于周期的因果解读**（今日强 → 归因于昨日资金已进场；今日弱 → 归因于昨日情绪/热度已达极值）」。
> 本文回答三件事：**能不能批量生成**、**覆盖到哪些模块**、**需要满足什么条件才能落地**。
> 同族权威文档：`design_赚钱效应亏钱效应_EffectEngine.md`。

---

## 一、结论速览

**能批量生成，但只能覆盖到「行业板块级」与「市场级」两层；题材级只能做一半。**

| 层级 | 周期归因可行性 | 依据 |
|---|---|---|
| **市场级**（情绪 / 赚钱亏钱效应 / 晋级率） | ✅ **齐备** | `feedback_matrix.trend.history`（5 日）、`summary_5d.trajectory`（情绪·晋级·核按钮三条序列）、`promo_*`（逐日真实溢价） |
| **行业板块级**（半导体 / PCB板 / 机器人…） | ✅ **齐备** | `cache/sector_flow_history/*.json` **11 天**逐日序列，单板块含 `pct / flow_yi / tx_flow_yi / tx_5d_yi / tx_10d_yi` |
| **题材级**（AI芯片 / 国产芯片 / 大消费…） | ⚠️ **只一半** | 有逐日涨停池（`zt_history`）可算「昨日家数/昨日是否首爆」，**但没有题材级资金流序列** —— 资金只有行业粒度 |
| **盘中实时卡（`/` 首页）** | ❌ **当前无跨日依据** | 卡面数据的「增量」是**同日内上一轮快照对比**，非跨日 |

一句话：**「昨日资金已进场」这句归因，行业板块级今天就能落地；题材级要先补一层「题材→资金」的桥。**

## 三、周期归因的数据依据（逐句可核实）

### 3.1 「今日强 ← 昨日资金已进场」

必需字段**已存在**于 `sector_flow_history/sector_flow_<date>.json::boards[板块]`：

```json
"半导体": { "pct": 2.1, "flow_yi": 74.48, "tx_flow_yi": -3.32,
            "tx_5d_yi": 25.61, "tx_10d_yi": 19.47, "is_focus": true }
```

- `flow_yi` = 当日主力净流入（亿）
- `tx_5d_yi` / `tx_10d_yi` = 腾讯口径 **5 日 / 10 日累计**净流入 → **这就是「昨日（更早）已有资金进场」的直接证据**
- **可用天数 11 天**（09-07 ~ 09-22，缺 09-21 断链日）→ T-1 / T-3 均值 / T-10 分位三层都能算

⚠️ 同口径提醒：`zt_history` 的历史日**无法回填**（`capture_daily.py` 无 `--date`），断链日的缺口会永久留在序列里。

### 3.2 「今日弱 ← 昨日情绪/热度已达极值」

需要的「昨日热度极值」可由三源合成，**均已有**：

| 证据 | 来源 | 形态 |
|---|---|---|
| 昨日该板块涨停家数占近 N 日分位 | `zt_history/zt_<date>.json::zt_list`（按 sector 聚合） | 现算 |
| 昨日该题材相位（boom / 分歧 / 衰竭） | `cache/market_memory_<date>.json`（`rose_topics` + 事件流） | 已有 |
| 昨日市场情绪 / 晋级率 / 核按钮 | `feedback_matrix.json::trend.history`（5 日）、`summary_5d.json::trajectory` | 已有 |

### 3.3 数据缺口（必须补齐才能做题材级）

1. **题材级资金流不存在** —— `sector_flow_history` 是**行业板块**（350 个），`eruption_history` 是**题材**（8~12 个）。两者没有映射表。
   ⇒ 题材级「昨日资金已进场」当前**无法直接生成**，只能用涨停家数替代（弱一档的证据）。
2. **`theme_series.json` 不是多日序列** —— 实测 `dates = ['13:29','13:59','14:29','14:59','15:00']`，是**当日 5 个盘中时点**。
   ⛔ 不能当 T-1 数据用（易误用，须在文档与代码注释里显式标注）。
3. **`pulse_snapshots/latest.json` 是单次快照** —— `sector_delta` 的 `板块(6→6)` 来自 `prev_map`（源码 `intraday_pulse.py:1492` 注释「对比上一次推送快照」）
   ⇒ **同日上一轮**，非跨日。所以在首页卡面说「较昨日…」是**编造**，必须换数据源。

## 五、落地条件（三件套 + 门禁）

### 条件 1 · 数据字段

| 需新增 | 粒度 | 做法 |
|---|---|---|
| **周期对比包** `ctx` | 板块 / 题材 | 每项附 `prev1`(T-1) / `avg3`(前 3 日均值) / `pctile10`(近 10 日分位) —— **现算，不落盘**（避免又一条需要守护的链路） |
| **题材→行业资金桥** | 题材 | 由 `eruption_history` 成分股 ∩ `sector_flow_history` 的行业，映射出题材级资金近似值；无重叠则降级为「仅家数证据」 |
| **昨日热度分位** | 板块 / 题材 | `zt_history` 逐日家数 → 近 10 日百分位 |

⚠️ **一律挂在既有路由上**，⛔ 不新增需要独立调度的产出文件（本系统已有过一次「盘后链断 3 天无人知」的事故）。

### 条件 2 · 周期对比维度（三层，口径冻结）

```
L1  T-1 边际      「较昨日 +N 家 / 资金 +X 亿」            ← 最直观，也最容易被质疑，须与源字段逐一对齐
L2  T-3 均值      「高于/低于近 3 日均值」                  ← 抗单日噪声
L3  T-10 分位     「近 10 日第 X% 分位（极值判定）」        ← 专供「昨日已达极值」这类归因
```

⛔ 档位阈值**一律复用** `scripts/feedback_matrix.py::sentiment_score` 的既有 if/elif 档，**不另立一套**（与 `lib/effect.ts` 同口径）。
⛔ 样本 < 10 天时**不出分位结论**，降级为「数据积累中」。

### 条件 3 · 话术模板（单一源）

**落点建议**：把 `scripts/card_copy_rules.py` 从「飞书卡专用」升级为「全系统白话单一源」，产出模板化短句；
前端只做**渲染**（或经路由透传 `narrative` 字段），⛔ 不在前端各页各写一套模板。

模板形（变量全部来自上文 `ctx`）：

```
【强·资金先行】{板块}今日 {pct:+.1}%（涨停 {n} 家，较昨日 {+d}）
              资金面：昨日主力 {flow:+.1} 亿，5 日累计 {tx5:+.1} 亿
              → 属「资金先行、今日兑现」型强势

【弱·热度极值】{板块}今日 {pct:+.1}%（涨停 {n} 家）
              昨日热度已达近 10 日 {pctile}% 分位（{phase}）
              → 属「过热回落」型走弱，非新逻辑破坏

【中性·无周期依据】数据不足，仅呈现当日读数
```

⛔ 严禁在话术里下预测性结论（只能说「属…型」，不能说「明天会…」）。

### 条件 4 · 门禁（当前**完全缺失**，是最大风险点）

- 前端目前**没有白话门禁**；后端 `card_copy_rules.py` 只管卡。
- 必须补：**对「被渲染的 JSON 字段」也跑一次 `scan()`**，零 FAIL 才允许进前端；
  或在前端加契约测试：**枚举字段必须命中映射表，缺省分支不得直出原 token**（可直接锁住本文 §2.1 那 4 处违规）。
- 验收判据：**渲染项集合 == 门禁检查项集合**（历史血案根因：「测试排除项 ≠ 实际渲染项」导致禁项漏网）。

## 七、风险与限制（必须同屏标注）

1. **因果 ≠ 相关**：`T-1 资金流入` 与 `今日走强` 是**统计共现**，不是已证实的因果。话术里用「属…型」而非「因为…所以…」。
2. **归因可证伪性**：现有 `scripts/factor_attribution.py` 已有「胜单/败单差值 + 样本边界」范式，落地时应**用同一套回测校验话术命中率**，不靠叙述自信。
3. **样本量**：`sector_flow_history` 仅 11 天，**10 日分位在数据补满前不可靠**；断链日缺口（09-21）永久存在。
4. **数据新鲜度**：日频源当日 17:19 后才更新（本文件写作时 `sector_flow` 最新 09-22、`summary_5d` / `promo_summary` 仍停 09-18）⇒ 页面须按**数据自身 date** 标注，⛔ 不用「当前时间」暗示它是新的。
5. **免责**：页面统一页脚 `基于公开信息与历史统计，仅供参考，不构成投资建议。`
