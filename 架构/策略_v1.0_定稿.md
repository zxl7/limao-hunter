## 0. 一页速览

**一句话定位**：只做**连板接力**（≥2 板在册票），在 09:25 有效竞价落地后判「这只票今天能不能接、买多重」，
**唯一优化指标是买入胜率**，不是晋级率、不是出手次数。

**五条铁律（违反任何一条即不算 v1.0）**

| # | 铁律 | 反面教材 |
|---|---|---|
| 1 | **盘后不定买哪只**，只出预案（focus/normal/avoid）；买哪只留到 09:25 | 用 14:58 快照冒充事前决策 |
| 2 | **晋级率只回答「这条线还活不活」**，绝不用于决定买不买 | 四条齐晋级 63.9%、当日买入 −2.28% |
| 3 | **提高胜率的第一反应不能是放宽门槛** | 真实链路回放：多抓机会把日均 +2.79% 打到 +0.84% |
| 4 | **绝对拒绝线只有两条**：竞价封死买不进、上方空间不够（赔率闸）；其余一律先降权再降仓，不径直否掉 | 11-05 只降权，结果买了扬子新材 −11.80% |
| 5 | **不改冻结件、不回填盈利日**；空仓单列，不算一笔交易 | 事后改 09:25 冻结结论充当事前判断 |

**这套策略赚什么钱**：连板票次日开盘到收盘之间的**承接差价**，不是「猜它明天还涨停」。
开盘位置能买且没透支，才有差价；开得越高，差价越可能已经被别人拿走 —— 全部分档数据都指向这一条。

## 1. 定位：为什么是这一套（三条实证的地基）

| 证据 | 数字 | 推出什么 |
|---|---|---|
| 晋级率与买入收益**反向**（30 日 / 314 样本） | 四条封板因子全中：晋级 63.9%、当日买入 **−2.28%**；全样本晋级 34.4%、−0.71% | 封板质量只预测**次日开多高**，不预测**买了赚多少** |
| 开盘幅度分档（同窗口） | 高开 >5%（买不到）晋级 **72.7%** / 收益 −2.64%；低开 >3% 晋级仅 10.0% / 收益 **+2.29%** | 想要高晋级 = 追买不到的位置；能买到的位置本来晋级率就低 |
| 交接力票的真实链路回放（35 日，含 11-06 收盘补齐） | 全关闸 22 天/75 笔/日胜 45.5%/累计 −7.43%；v1.0 19 天/54 笔/日胜 **57.9%**/累计 **+2.56%** | 「少做 + 砍高开档」在当前窗口是正期望方向，**但幅度有限、且回撤更大** |

⚠️ 三条都是**同窗口描述**（9 月中~11 月初），未跨周期验证。⛔ 不宣称「未来一定提高胜率」。

## 2. 单笔交易的完整决策链（v1.0 定格）

```
【T-1 15:30 盘后】
  全市场涨停池（zt_history，60~90 只）
   → daily_screen 全量过筛（逐只 pass / watch_only / reject，只做减法）
   → seal_gate 成交额与封板形态（一字板 / 换手板分口径）
   → pool_admit 成交额阶段门槛 → 各降级闸 → 两池（接力 / 观察）
   → relay_forecast 挂「明早大概率开在几个点、几成买不到」
   → candidates-<T-1>.json（bias 预案，⛔ 不含买入决定）

【T 09:25 竞价落地后】
  candidates-<T-1> + auction_quotes-<T>（真实竞价）
   → pool_call 逐票短路链（见 §3.1，顺序不可乱）
   → 观察票复核通道（state 可翻案，hard 不可）
   → defense_gate 环境定调 → 名额 effective_quota
   → 排序取前 N → ai_caliber.decide（成交判据）→ position_cap
   → pool_call-<T>.json 冻结（09:25:30 前禁止冻结）

【T 日盘中 / T+1】
  → 账本按「T 日开盘买 → T 日收盘卖」记评估代理
  → T+1 收盘口径另记（可执行往返，不等于券商成交）
  → 战绩分三张表，禁混账（见 §3.6）
```

**关键时间纪律**：09:25:30 前冻结一律无效；陈旧旁白不注入也不阻塞裁决。

## 3. 判据总表（唯一源 / 默认值 / 回退）

### 3.1 准入：09:25 逐票短路链（顺序即优先级）

| 序 | 判据 | 阈值（v1.0 默认） | 结果 | 唯一源 |
|---|---|---|---|---|
| ① | 无有效竞价 | `auction_price` 缺失 | watch | `pool_call` |
| ② | **竞价封死买不进** | `gap ≥ 涨停幅度 − 0.2pct` | skip（绝对线） | `pool_call` |
| ②′ | **上方空间不够（赔率闸）** | `room = 涨停幅度 − gap < 涨停幅度 × 0.5`；10cm⇒gap>5%、20cm⇒gap>10% | skip（绝对线） | `pool_call.HIGH_GAP_ROOM_MIN=0.5` |
| ③ | 盘后预案＝回避 | `bias=avoid` | skip | `candidates` |
| ④ | 明显低于预期 | `DEV = gap − E < −2.0`；缺 E 不裁 | skip | `ai_caliber.EXPECTED_GAP_DEV_MIN` |
| ⑤ | 孤苗高开派发 | 自身 `gap≥3%` ∧ 同族其余红开率 <40% | watch | `pool_call` ⑪d |
| ⑥ | 量能干涸 | `竞价额 / 目标额 < 0.35` | watch | `ai_caliber.VOLUME_DRY_RATIO` |
| ⑦ | 身位差过大 | 同题材最高板 − 自身 ≥2 板 | watch（不占名额） | `pool_call.LEADER_ONLY_MAX_GAP=2` |
| ⑧ | 薄封最高板 | 最高板 ∧ 封单/流通 <2% | watch | `pool_call.POOL_CALL_THIN_SEAL_TOP` |
| ⑨ | 环境防守 | `defense_gate` 命中 ≥5 条 | 名额→0 | `defense_gate.ENV_BLOCK_HITS` |
| ⑩ | 名额 | `effective_quota=0` | 全 watch（空仓合法） | `pool_call` |

⚠️ ②′ 是 11-06 新增、对 11-05「删掉 5% 线」的**定向修正**：旧线按绝对百分比砍（20cm 被误伤），
②′ 按**赔率**（还剩多少空间）判，且按涨停幅度归一 ⇒ 10cm 的 5% 与 20cm 的 10% 等价，⛔ 不给创业板额外打折。

**"是否符合预期"的唯一判据仍是 `gap_zone(DEV)`**：`DEV<−2` 放弃，其余（高开/低开/超预期）都算符合。
⛔ 不存在「必须红开」「高开超 5% 就买不到」这类绝对线（11-05 17:00 已删除，常量 5 不参与裁决）。

### 3.2 量能：三档，不猜

| 档 | 竞价额 / 目标额 | 仓位处理 | 复核含义 |
|---|---|---|---|
| full | ≥ 0.70 | 正常 | 可进入完整复核链 |
| soft | 0.35 ~ 0.70 | 可买，降仓（0.50~0.75 / 0.35~0.50 两段） | ⛔ 不能走 state 复核 |
| dry | < 0.35 | 只观察 | — |

- 目标额 = 昨日成交额 × 3%（`need_yi`，与 `pool_call` 同源口径）。⛔ 不能用「竞价额 ÷ 昨成交额」判强弱（那个比值天然只有 3~15%）。
- `POOL_CALL_VOLUME_SOFT` **默认关**：回放 4 天名单被改、日均 2.79%→1.30%，量能门在实盘是救钱的。

### 3.3 权重与仓位：高开只降权、不否决（除 ②′ 外）

| 因子 | 取值 |
|---|---|
| 绝对档 `near = gap / 涨停幅度` | 0.60 / 0.70 / 0.80 → 权重 0.70 / 0.45 / 0.30 |
| DEV 透支档 | `DEV≥4` ×0.75；`DEV≥6` ×0.60 |
| 下限 | 0.20（>0，永远留试错仓） |
| 最终仓位 | `position_cap = even_cap × min(volume_scale, gap_weight)` |

- `even_cap = min(50%, 100% / N)`，N = 当日参与只数。
- ⚠️ ②′ 落地后 10cm 的 `gap/limit` 最多只到 0.5 ⇒ 绝对档打不到，真正生效的只剩 DEV 透支档。
- 回撤缩仓 `POOL_CALL_EVEN_RESPECT_DRAWDOWN` **默认关**。

### 3.4 股性 / 身位 / 板块 / 梯队

| 维度 | 判据 | 关键口径 |
|---|---|---|
| 股性 | `core/zt_gene.py` | 近一年涨停次数、历史晋级率；术语只许「连板龙 / 老龙头 / 连板 / 难连板」 |
| 身位 | 同题材**最高板**为分母（11-06 改），差 0/1/≥2 板 → 权重 0.75 / 1.0 / 0.40，下限 0.20 | 只降仓不剔除；缺题材不裁；盘后不得因身位 reject |
| 板块龙一 | `core/sector_leader.py` 唯一源 | 板数 → 封板时段 ±5min → 封单/流通 → 带动家数 → 时间 → 代码；只降不升 |
| 梯队 | `boards ≤ 2` **免判**；≥3 板仍要 `ladder_has_complete or ladder_health ≥ 6.0` | 1~2 板用梯队筛是**反向选择**（有梯队 −2.52% vs 无梯队 −0.07%） |
| 四条件合取 | 非孤军题材龙 ∧ 非 ice ∧ 阶段量能 ∧ 梯队 | 缺板数不豁免，留痕 `ladder_waived` |
| 成交额（封板形态分口径） | **一字板**：沿用原阶段门槛（1~2 板 3 亿 / ≥3 板 5 亿），低成交额是「9:25 就封死」的结构必然，⛔ 不加分也不扣分；**换手板**：1~2 板提到 **≥5 亿**（`TURNOVER_BOARD_FLOOR_YI`），≥3 板本就 5 亿 | 换手板 <5 亿三档全亏（−1.5%/−4.5%/−3.3%），≥5 亿才转正 |

### 3.5 环境与名额

| 项 | 默认 | 说明 |
|---|---|---|
| 环境弱判据 | 情绪 <2.0 / 晋级率 <25% / 核按钮 >8 / 真破位 ≥2 / 炸板率 ≥40% / 昨涨停红开 ≤40% / 昨连板红开 ≤25%（**7 条计票**）；读数覆盖率 <70% 时该票不参与 | 数据缺 → 该票不投票，不猜 |
| 名额降档 | 命中 ≥3 条 → 压到 1 只；命中 ≥5 条 → 不主动买（名额 0） | 11-06 由 2/3 上调为 3/5，仍可 `ENV_BLOCK_HITS` 覆盖 |
| 名额基数 | attack 3 / selective 2 / defend 1 / hibernate 0 | `POOL_CALL_UNLIMITED_SLOTS=1` 时 quota≥1 不限只数，但仍受仓位上限约束 |
| 空仓合法性 | ✅ | 空池、名额 0、候选全被拒是**三个独立原因**，不合并解释 |

### 3.6 复核通道与三张成绩单

- 复核分类：`hard`（一字/薄封/ST/688，不可翻案）/ `state`（可完整复核，须量能 full）/ `restricted`（个股级准入未过，复核后仍观察）。
- 下游解锁唯一源 `two_pool.rechecked_entry`（state ∧ rechecked_from_observe ∧ participate），决策/账本/验证统一消费。
- 成绩单**禁混账**：①核心与晋级跟踪 ②系统决策评估（开盘→收盘是代理，不是 T+1 真实收益）③真实成交战绩（需券商回报或用户确认，无记录标缺失）。

**每日池内台账（2026-11-06 上线，`cache/pool_ledger/<date>.json`）**

每天 16:00 由 automation「【盘后】池内台账·竞价→收盘」跑 `scripts/pool_ledger.py`，把池内每只票写成一行：
今开幅度 / 竞价额 / 裁决 / 竞价价 / 开盘 / 最高 / 最低 / 收盘 / **09:25 竞价价买→当日收盘卖** / 当日涨幅 / 是否封板。
一字板与竞价封死标 `═`/`锁`，不计入统计；**缺当日 K 线就 `exit 2`，不写半截文件**（堵 15:19 基线虚报的那个洞）。
终端一次给出：可成交只数、平均/中位/胜率/最好/最差、按裁决分组、按今开分档、以及 `--days N` 的多日汇总。

## 8. 怎么判断"违反了 v1.0"

出现以下任一，即为偏离，须回改或明确记录为临时实验：

1. 用晋级率、封板质量、热度单独作为买入理由；
2. 为了"多抓机会"放宽任一门槛（须先跑 `research_high_gap_ab.py` 验收）；
3. 事后修改冻结件、把空仓日算成交易、把回放结果当真实成交；
4. 新增硬闸却没有可逆开关；
5. 在本文件与 `shared_rules.md` 之外的地方另写一套阈值。

> **免责**：本策略基于公开数据与历史窗口统计，不构成投资建议；所有收益数字均为回放口径，非券商成交。
