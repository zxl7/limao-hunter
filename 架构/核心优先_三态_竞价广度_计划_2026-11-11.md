## 1. 目标口径（先把话定死，再谈代码）

### 1.1 五条顺序（⛔ 不可跳步）

```
① 定对象：谁是核心（同题材身位），哪些只是比较对象 —— 不能靠板数等同身份
② 定买点：核心值得看 ≠ 竞价这个价格值得买
③ 出三态：可买 / 核心仍在但价格不合适 / 核心失效（⛔ 不许塞成"买或放弃"）
④ 看广度：这条线**昨日涨停的全体**今天开在哪（不只前五）
⑤ 判替代：其他票必须有**独立成立依据**，不能因为核心贵就获得替代资格
```

### 1.2 三态定义

| 状态 | 触发 | 动作 | 卡面 |
|---|---|---|---|
| **A 可买** | 核心成立 + 价格合格（现有闸门全过） | 买 | 正常买入块 |
| **B 核心在、价不合适** | 核心仍强（未断板/未破位），但竞价价格赔率差（高开过顶、room 不足） | **不买，且不发替代资格** | 「核心在，价格不合适 → 这条线今天可以不做」 |
| **C 核心失效** | 核心**收盘确认**断板 / 破位 / 判断被推翻 | 整条线不做 | 明写失效原因（⛔ 不得用盘中未收录代替） |

### 1.3 竞价广度（新增维度，回答"后排掉队"）

对**昨日该线全部涨停票**（不是前五、不是候选池）统计 09:25 竞价：

| 指标 | 定义 |
|---|---|
| `n` | 昨日该线涨停家数 |
| `underwater` | gap < 0 的家数与占比 |
| `deep_under` | gap ≤ −3% 的家数 |
| `median_gap` | 竞价中位涨幅 |
| `front_gap` | 前五（按身位）的中位涨幅 |
| `divergence` | `front_gap − median_gap`：前五好、整体差 → 分化风险 |

**判读（初版，待回测校准）**：
- 全体强（中位 > 0、水下 < 25%）→ 承接好；
- 前五强 + 水下 ≥ 40% → **分化**：前排可能独木难支，B 态更应保守；
- 全体弱（中位 < −1%、水下 ≥ 50%）→ 这条线今天直接降级。

> 今日实测（11-11 09:25，全覆盖 93/93 只昨涨停）：
> 机器人 29 只 · 水下 7（24%）· 中位 +2.00% → 尚可；
> 短剧/互动影游 13 只 · **水下 6（46%）** · 中位 0.00% → 分化；
> 光伏 3 只 · 水下 1 · 中位 +3.47% → 强。
