# 板块优先选股 · 方案研究（2026-11-11）

> 用户口径：「先看昨天最强/前三强的板块，再在板块里按涨停时间、累计涨幅、带领性推龙头，最后接力龙一/龙二。」
> 本文只做**可行性研究**：数据在不在、要动哪些东西、身位键怎么排。**不跑回测。**
>
> **2026-11-11 P0 已落地**（只读落盘，不碰买入链路）：
> `scripts/snapshot_theme_ladder.py` → 每日写 `cache/theme_strength_<date>.json`
> 与 `cache/ladder_rank_<date>.json`；已回填 38 个归档日；`capture_daily` 第 16 步接入。
> 板块强度**复用生产口径** `core/market_theme_rank.py`（高度/梯队为主、家数弱辅助），
> 快照里用 `strength_basis` 标出口径；该模块不可用时回落到家数主序并在 `caliber` 写明。
> 身位快照同时落 **三套排名**：`rank_current`（现行）、`rank_proposed`（板数→20日→5日）、
> `rank_momentum`（用户字面口径：累计涨幅主序）——半年后回测比的就是这三套。

---

## 1. 逻辑拆解（四步，每步都要有单一数据源）

```
① 板块强度排序（昨天收盘）  →  ② 取前三强
                                        ↓
③ 板块内身位排序（龙一~龙五） ← 涨停时间 / 累计涨幅 / 带领性 / 封板质量
                                        ↓
④ 接力 = 该板块龙一（必要时龙二），跨板块不比较
```

### 2.2 缺失（方案必须补的）

| 缺口 | 影响 | 补法 / 成本 |
|---|---|---|
| **回封时间** | 只有首封 `fbt` + 炸板次数 `zbc`，**分不清「一次封死」和「炸板后回封」**（福莱新材：首封 09:32、炸板 2 次、实际回封很晚） | 需从分时/逐笔算，属**采集层改造**；短期只能用 `fbt + zbc` 近似，并在口径里注明 |
| **5 日 / 20 日累计涨幅** | 现在只有 10/30 日 | 用 `kline_qfq` 现算，落一个新字段即可（**低成本**） |
| **板块强度分（单一源）** | 现在有家数、有 tier，但没有"强度分 + 排名 + 是否前三" | 新建 `core/theme_strength.py`，按「涨停家数（主）+ 连板高度（辅）」出分与排名，**每日落盘** |
| **板块强度历史序列** | 只有当日字段，回测无法复现"昨天谁最强" | 每日落 `cache/theme_strength_<date>.json`；历史可用 `zt_history` 回算（仅 38 天） |
| **每日身位快照** | 没有"某日某板块的龙一~龙五"存档 | 每日落 `cache/ladder_rank_<date>.json`（只读计算，**这是半年后回测的关键底料**） |
| **题材分组稳定性** | `theme` / `sector` / `theme_em_name` 多套口径，`theme_name` 曾为 `None` | 定一个 `theme_key` 单一源（建议用 snapshot 的 `theme_base`），并在候选行落 `theme_key` |

## 3. 身位键（龙一~龙五）因子表

目标键（越小越强）：**板数 → 累计涨幅 → 封板质量 → 带领性 → 首封时间 → 代码兜底**

| 序 | 因子 | 系统现状 | 需构建 | 数据成本 |
|---|---|---|---|---|
| 1 | **连板数** | `boards` | 无 | 0 |
| 2 | **累计涨幅** | `ret_10d/30d`（未参与排序） | 补 `ret_5d/20d`，并接入排序 | 低（K 线现算） |
| 3 | **封板质量** | `fbt`（首封）、`zbc`（炸板次数）、`seal`（封单） | **回封时间**（缺）；封装成 `seal_quality` 分 | 中（采集改造） |
| 4 | **带领性** | `carry_cnt` / `carry_score` / `theme_mates_cnt` | 定义与文档化（现在只在代码里） | 低 |
| 5 | **首封时间** | `fbt` | 无（但应降为同层 tiebreak，而非主序） | 0 |
| 6 | 兜底 | `code` | 无 | 0 |

> ⛔ 现状问题：`leader_key` 第 3 序是「封板时段档」，**累计涨幅完全不在键里**——所以福莱新材（20 日 +110%）在同题材只能排第 9。

| 阶段 | 内容 | 目的 | 是否动买入 |
|---|---|---|---|

## 6. 风险清单

1. **板块强度口径冲突**：已有 `themeTier` / `theme_mates_cnt` / `theme_has_sector_effect`，新分若不复用会形成第三套口径。
2. **题材分组漂移**：`theme` vs `sector` vs `theme_base`，同一只票可能被分到不同板块 → 身位算错（11-10 光洋 `dragon_rank=None` 就是这个）。
3. **回封时间不可得**：短期只能近似，别把近似值写进硬判据。
4. **跨板块比较**：⛔ 任何"全市场按分数排序"都与用户口径冲突，展示层要按板块分组。
5. **数据只有 38 天**：任何回测结论都要标注样本量，避免过度解读。
