# 龙头基因沉淀池 · 设计与实现（2026-11-10）

> 用户口径：「连续涨停 ≥4 板自动入池；5 板及以上视为有望突破板块、成为市场情绪龙头的强票；
> 断板后两个交易日内累计跌幅不得超过 10%；出现 A 杀则判定不具备龙头属性，剔除或标记淘汰。」

| 层 | 产物 |
|---|---|
| 规则与判定 | `scripts/dragon_gene.py`（只读归档 → `cache/dragon_gene.json`） |
| 回归锁 | `tests/test_dragon_gene.py`（6 例：门槛 / 强票 / 保留 / A杀 / 待判 / 盘中归档不可当断板） |
| 接口 | `/api/dragon/gene`（`routes.ts` ↔ `serve.py` 双源一致，89/89） |
| 终端 | `/dragon-gene` 页（盘面段 · 「龙头基因」） |

---

## 1. 入选条件

| 项 | 规则 |
|---|---|
| 门槛 | **连续涨停 ≥ 4 板**（`boards >= 4`），首次达到该板数的交易日 = `entry_day` |
| 连续性 | 相邻**交易日**、板数逐日 **+1**；断档或板数归 1 → 视为**新的一段**（N 字二波算新一代，`generation` 递增） |
| 数据源 | `cache/zt_history/zt_<date>.json` 的 `zt_list`（当日收盘归档，含逐票 `boards`） |
| 强票 | 该段**最高板 ≥ 5** → `strong: true`（有望突破板块、成为市场情绪龙头） |
| ⛔ 不入池 | 3 板及以下；只盘中出现、收盘未封的（归档只记收盘涨停） |

## 2. 跟踪字段

| 字段 | 含义 |
|---|---|
| `entry_day` / `entry_boards` | 首次达到 4 板那天 / 当时板数 |
| `max_boards` | 这一段走到的最高板 |
| `strong` | 最高板 ≥5 |
| `status` | `tracking` 在途 / `pending` 待判 / `retained` 保留 / `eliminated` 淘汰 |
| `current_boards` | 在途时的当前板数 |
| `break_day` | 断板日 = 最后一个涨停日的**下一个交易日**（以真实 K 线日校正，停牌自动顺延） |
| `d1_pct` | 断板当日相对基准的涨跌幅（仅参考） |
| `d2_pct` / `post_2d_pct` | 断板后第 2 个交易日相对基准的**累计**涨跌幅 |
| `a_kill` | 两日累计 ≤ −10% → true |
| `generation` | 同一代码第几代入池（淘汰后再次 4 板 = 新一代） |
| `price_note` | 基准价来源异常时的说明（K 线缺失回落 `zt_list.price`） |

## 3. 判定逻辑

```
                ┌──────────────┐
  涨停且 ≥4板 → │  tracking    │ 段仍在延续（最后一根涨停在最新归档日）
                └──────┬───────┘
                       │ 下一个交易日未涨停
                       ▼
                ┌──────────────┐
                │  pending     │ 不足两个交易日 / 停牌缺 K 线 → 不判
                └──────┬───────┘
                       │ 满两个交易日
          ┌────────────┴────────────┐
          ▼                         ▼
   累计 > −10%                 累计 ≤ −10%（A 杀）
   ┌──────────┐               ┌────────────┐
   │ retained │               │ eliminated │
   └──────────┘               └────────────┘
```

**基准价**：最后一个涨停日的**收盘价**。
**两日跌幅**：`close(断板后第 2 个交易日) / close(最后涨停日) − 1`。
**A 杀阈值（2026-11-10 用户「可以区分口径」·已定）**：**一个跌停板**

| 板型 | 阈值 | 含义 |
|---|---|---|
| 主板 10cm | **−10%** | 两个交易日跌掉一个跌停 |
| 创业板/科创板 20cm | **−20%** | 同上，按幅度归一 |
| ST 5cm | **−5%** | 同上 |
| 北交所 30cm | **−30%** | 同上 |

绝对 −10% 仍写进 `a_kill_abs10` 作对照（便于回看两种口径的差异，⛔ 不参与淘汰判定）。
**淘汰 ≠ 删除**：只改状态，记录留在池里——池子的价值就是「样本 → 存活率」统计，删了就统计不出来。

## 4. 边界与诚实降级（⛔ 都不许猜）

| 情形 | 处理 |
|---|---|
| **盘中归档**（`intraday_only`，无 `zt_list`） | 整天**跳过**，`skipped_days` 记录。⛔ 不能当「当天没涨停」，否则把还在连板的票凭空判成断板（10:41 实测踩到） |
| 归档日 `zt_list: []`（真的有 0 家涨停） | **有效数据**，正常参与序列 |
| 断板后只过了一个交易日 | `pending`（等下一个交易日） |
| 停牌 / 缺 K 线 | `pending` 或按下一根可用 K 线顺延，`price_note` 写明 |
| 20cm / ST / 北交所 | **按板归一**：阈值 = 该票一个跌停板幅度（见 §3 表），由 `limit_pct()` 按代码/名称推断 |
| 断板后再次 4 板 | 新 `generation`，历史段保留 |

## 5. 当前实测（数据截至 2026-11-09）

| 指标 | 值 |
|---|---|
| 窗口 | 2026-09-10 ~ 2026-11-09（37 个完整归档日） |
| 入池 | **42 只**（强票 18） |
| 在途 / 待判 / 保留 / 淘汰 | 1 / 3 / 30 / 8 |
| 保留率 | **78.9%** |
| A 杀率 | **21.1%** |

样例：

- `002578 闽发铝业`：11-05 入池（4 板）→ 最高 6 板，仍在途；
- `002790 瑞尔特`：9-11 入池 → 9-14 断板，两日 **−19.01%** → A 杀淘汰；
- `000993 闽东电力`：最高 6 板，两日 **+6.06%** → 保留。

## 7. 已定（2026-11-10 用户拍板）

| 事项 | 结论 |
|---|---|
| 是否接入每日定时 | ✅ **挂在盘后复盘**：`capture_daily.py` 第 15 步自动派生（不新建定时任务）；17:50 落盘守护按盘后覆盖判据校验 |
| 10% 阈值是否按板归一 | ✅ **区分口径**：阈值 = 一个跌停板（10cm −10% / 20cm −20% / ST −5% / 北交所 −30%）；绝对 −10% 保留为对照字段 |
| 淘汰后是否允许复活 | ✅ **允许**：同代码再次走出 4 板 = 新 `generation`，历史段保留（当前实现即如此） |
