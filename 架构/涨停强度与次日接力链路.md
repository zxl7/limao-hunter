# 当日涨停强度判断 + 次日接力决策（链路规范）

> 定稿 2026-10-21。体系来自用户口述，落地代码 `wealth_code/core/anchor_call.py`
> ＋ `wealth_code/core/pool_call.py`（第⑥b 道「锚点闸」）＋ `wealth_code/core/front_core.py`（身位）。
> 契约锁 `tests/test_anchor_call.py`（41 例）、`tests/test_front_core_backrow.py`（12 例）。

---

## 0. 一句话

**收盘看时间定地位，开盘看锚点定出手。** 涨停时间决定谁是前排，次日只做一件事——
看昨天那位"前排大将军"今天以什么姿态开盘（一字 / 大高开 / 强开 / 平开 / 破预期），
姿态确认后，才在线内挑一只容量够的核心接力。

---

## 1. 为什么是"涨停时间"而不是"涨幅/板数"

同一根涨停 K 线，封板时间不同，背后的资金性质完全不同：

| 封板时点 | 资金性质 | 次日可信度 |
|---|---|---|
| 09:25–09:30（竞价顶板） | 隔夜一致性极强，钱排队等开盘 | 最高，但**买不到** |
| 09:30–09:45（开盘抢筹） | 主动抢，抢在消息扩散之前 | 高 |
| 09:45–10:30（上午主攻） | 盘中确认后跟进 | 中 |
| 10:30–13:30（午后跟随） | 被板块带起来的被动跟随 | 低 |
| 13:30 之后（尾盘偷袭） | 尾盘拉、偷袭做图形 | 最低 |

**涨幅相同、板数相同，尾盘封的那只很可能只是"跟出来的"**。所以时间必须排在板数前面——
这也是系统里 `anchor_call.pick_general()` 把时间作为第一排序键的原因：尾盘封板带 9 家的票，
不能顶掉 09:31 封板带 3 家的真先锋。

## 环节一：当日涨停强度（收盘后·缩范围）

### 观察指标

| 维度 | 字段 | 权重 | 含义 |
|---|---|---|---|
| **时间节点**（核心） | `fbt` | 45% | 越早越强，五档见上表 |
| 带动性 | `carry_cnt` | 25% | 封板后带起几家同线涨停；0 家＝独苗 |
| 封板质量 | `zbc`、`seal_ratio_pct` | 20% | 炸板次数越少越硬；封单/流通越厚越硬 |
| 板块成片 | `theme_mates_cnt` | 10% | 同题材涨停家数，孤军票打折 |

⛔ **刻意不含涨幅、不含板数**——板数已由身位与高度另算，混进来会把高位票无脑顶到前面。

### 判断顺序

```
1. 先算节点档（时间）           → 决定这只票的"资金性质"
2. 再算强度分（0~100）          → 同一条线内部横向比
3. 选大将军：时间 → 带动 → 板数 → 封单，逐级比较
4. 标板位：首板 / 一进二 / 加速板 / 高位分歧
```

第 3 步的排序键是**硬的**，不允许"综合看"——因为大将军这个角色是用来当**次日锚点**的，
它必须唯一、可复现，否则次日无法做对比。

### 触发条件（进入候选池）

- 强度分 ≥ 同线中位数，且节点 ≤ 上午主攻（`main`）：**前排候选**
- 节点 = 尾盘偷袭（`tail`）：只能进观察池，⛔ 不得当大将军、不得当次日锚点
- 独苗（`carry_cnt = 0` 且 `theme_mates_cnt ≤ 1`）：强度分打七折，不进前排

## 环节二：角色分工——龙头 vs 前排大将军

这两个概念经常被混用，但在链路里承担**完全不同**的作用：

| | 龙头 | 前排大将军 |
|---|---|---|
| **定义** | 空间最高 + 全市场认同（跨线唯一性） | 单条线里**最先封 + 带动最多 + 封得最硬** |
| **判断依据** | 板数天花板 + 跨板块辨识度 + 连续记录 | 封板时间 + 带动家数 + 封单质量 |
| **管什么** | **敢不敢做**（今天整体要不要出手） | **这条线能不能打**（今天这个方向要不要出手） |
| **在链路中的位置** | 环境层（大盘基调） | 执行层（每条线一个锚点） |
| **失效标志** | 龙头断板 / 被核按钮 / 停牌核查 | 次日竞价破预期 |
| **能否被替代** | 不可替代（它没了就是情绪断点） | 可替代（同线第二只接位，但降级） |

**三条硬关系：**

1. **龙头必须有大将军属性**——龙头一定是它那条线里封得最早、带动最多的那只；否则只是"高度最高"，不是龙头。
2. **大将军可以不是龙头**——大量线只有大将军没有龙头（高度不够 5 板）。这种线可以打，但仓位要小。
3. **龙头断板后由大将军接位**，该线降级为"无龙头接力"：只允许在锚点买不到时打隔壁，⛔ 不允许当核心打。
   （这就是系统里 `line_core.broken = True` 时后排闸不拦、只标注"买的是隔壁"的原因。）

**为什么锚点要用大将军而不是龙头？**
因为龙头经常一开盘就买不到（一字/大高开），而大将军是**可观察、可对比**的那只——
它今天怎么开，直接反映这条线还有没有钱愿意接力。龙头一字是"结果"，大将军开盘姿态是"过程"。

---

### 一线反例：锚点根本不存在时，不要一律放弃

10-21 传媒线：昨日核心新华传媒（11 板）**已断板** → 按规则它不能当锚点 → 这条线"没有锚点"。
如果按"没有锚点就不做"处理，就会错过当天唯一的正确买入：

| 票 | 节点 | 昨日强度 | 今日竞价 | 当日结果 |
|---|---|---|---|---|
| 南威软件 603636 | **尾盘偷袭**（14:13 封） | 37.4（全池偏低） | 平开 +0.67% | **+10.01% 涨停** |

**结论**：锚点缺失 ≠ 这条线不能做。核心断板、锚点买不到，正是用户说的"买隔壁"场景——
此时判据从"锚点强不强"切换成"**这只票自己是不是线内最靠前的那只**"（由身位闸承担）。
把"没有锚点"当成否决条件，会把系统打成长期空仓。

## 环节三：次日锚点对比（09:25，五分钟内定完）

### 观察对象

- **主锚点**：昨日大将军（同线核心，且昨日未断板）
- **副锚点**：昨日龙头（若与大将军不是同一只）——两者背离时以大将军为准，因为它是可成交的那只

⛔ 已断板的核心**不能当锚点**：它今天不是涨停股，它怎么开说明不了这条线的强弱。

### 五档判读（唯一判据 = 09:25 竞价）

| 档位 | 判据 | 含义 | 对这条线意味着什么 |
|---|---|---|---|
| **一字顶板** | 开在涨停价（10cm/20cm 分别判定） | 态度最强 | 买不到 → 只能看隔壁 |
| **大高开** | gap > 5%（用户硬线） | 强，但无仓位可上 | 买不到 → 只能看隔壁 |
| **强开** | 2% ≤ gap ≤ 5% | 前排确认 | **唯一可执行窗口 → 打核心** |
| **平开** | 0 ≤ gap < 2% | 态度不明 | 只看，等它拉起来 |
| **低开 / 破预期** | gap < 0，或低于昨日预期下沿 | 前排转弱 | 这条线今天作废 |

**关于"以一字表明态度"**：一字的意义不是"更强所以更该买"，而是**它替这条线做了背书**——
前排敢一字，说明接力资金还在，所以**线内的第二只才是标的**。把一字读成"要买它"是这条链路上最常见的错。

### 判断顺序（固定，不可并行、不可跳步）

```
① 锚点破预期？ ──是──→ 整条线放弃（最强否决，不再看第二个指标）
        │否
② 锚点一字 / 大高开？ ──是──→ 线强势但锚点买不到 → 只在"隔壁"里挑
        │否
③ 锚点强开 2%~5%？ ──是──→ 线确认 → 在线内挑容量合适的核心
        │否（平开 / 低开）
④ 只看，不出手
```

顺序不能换的理由：**先用最便宜的信息（一个数字）排除掉大部分错误的线，再花精力挑票**。
反过来先挑票，会在走坏的线上找出"看起来很强"的个股——那正是账户过去大亏的主要来源。

## 环节四：选核心接力（前排确认之后）

锚点确认强开后，才允许在这条线里挑标的。挑的是**容量合适**的核心，不是最强的那只。

| 指标 | 门槛 | 为什么 |
|---|---|---|
| 成交额 | ≥ 5 亿 | 用户硬线；太小的装不下资金，进出就砸 |
| 成交额上限 | 参考 25 亿（换手为主） | 太大说明分歧重、上方套牢多 |
| 换手 | 3% ~ 25% | <3% 没换手（一字/惜售）；>25% 派发 |
| 封单/流通 | ≥ 0.5% | 薄封单＝假封板，一砸就开 |
| 炸板次数 | ≤ 1 次 | 炸 3 次以上＝封板质量差 |
| 身位 | 前排或次排 | 后排不接（后排没溢价） |
| 筹码获利盘 | < 95% | ≥95% 全员盈利，风吹草动就砸 |
| 位置 | 30 日超额 < 50% | 太高＝二波反抽，不做 |
| 主力资金 | 当日净流入 ≥ 0 | 流出＝借涨停出货 |

**容量合适 ≠ 强度最高**。最强的往往已经一字或大高开（买不到），次强的反而封单厚、换手健康、
装得下钱——这才是接力的对象。

## 环节五：失效与放弃（写死，不留解释空间）

### 单条线层

1. **锚点破预期** → 整条线当日作废（低开 >1%，或低于昨日预期下沿）。
2. **锚点一字/大高开，但线内没有第二只跟**（孤军）→ 不买隔壁，空仓。
3. **锚点大高开后炸板、30 分钟内回不去** → 该线当日作废。
4. **前排大高开、后排全线低开**（分歧）→ 只做锚点本身（若买得到），不做接力。
5. **大将军是 13:30 后才封的** → 它的次日锚点**可信度打折**：不作为"这条线很强"的证据
   （⛔ 不许因为它的姿态去追线内的其它票），但它**自己**今日强开时仍可按正常流程参与。
   ⚠️ 反例已在案：10-21 传媒线大将军南威软件是 14:13 尾盘封的（节点＝尾盘偷袭·强度仅 37.4），
   次日平开 +0.67%、当日收 **+10.01% 涨停**（买入价 → 现价 +9.27%）。所以这条是**降权，不是否决**。
6. **接力标的容量不达标**（成交额 <5 亿 / 封单<0.5% / 换手>25%）→ 不接。
7. **位置太高**（30 日超额 >50% 且断板 ≥3 日后重启）→ 二波反抽，不做。
8. **锚点与指数背离且锚点走弱** → 以锚点为准，指数不救个股。

### 市场层

9. **≥2 条线的锚点同时破预期** → 当日整体空仓（多点同时崩＝情绪断点）。
10. **1 条破预期且无任何强开** → 最多只做最强的那一条线。
11. **核按钮 ≥5 或晋级率 <25%** → 名额降档（与既有环境防守腿同源，不重复计）。

### 时间层

12. **09:30 后锚点跌破均价且未回封** → 放弃该线（锚点失效，不等尾盘）。
13. **锚点迟迟不表态（平开横盘到 10:00）** → 视为"未确认"，当天不接力。

**时间定身份，锚点定手脚。**
大将军一字 → 打隔壁；大将军强开 → 打核心；大将军破预期 → 这条线今天不存在。
