# 界面用语规范（2026-11-16）

> 用户定调：**当作 C 端产品来写**。能说人话就不说术语；必须用时，用交易者自己的词。

## 三条规则

1. **不显示字段名/实现细节**：`zt_series`、`null`、`confidence_factors`、`reference_only`
   这类只在代码里出现，界面上一律翻译成人话。
2. **先给人话结论，再给数字**：数字后面跟一句「所以呢」（例：连着流入 3 天 > 单日砸 1 个亿）。
3. **同一件事同一个说法**：全站统一，不这里叫「回流」那里叫「轮动」。

## 保留的「行话」（交易者本来就懂，**必须保留**）

涨停 / 连板 / 晋级率 / 核按钮 / 断板 / 封单 / 炸板 / 溢价 / 接力 / 排板 /
回流 / 埋伏 / 分歧 / 退潮 / 卡位 / 中军 / 身位 / 潜伏 / 试盘 / 扩散

用户 2026-11-16 明确：**用词要专业**。上面这些是交易语言，换成大白话反而外行。
真正要去掉的是**工程词**：字段名（`zt_series`）、`null`、`快照`、`口径`、`产物`、
`降级`、`兜底`、`阈值`、`接口`、`路由`。

## 推送卡片（WorkBuddy / 飞书）同规

卡片和终端是**同一套话术**，只允许空间差异，不允许用词差异。

| 规则 | 说明 |
|---|---|
| 禁用词相同 | 快照 / 落盘 / 兜底 / 降级 / 阈值 / 产物 / 字段 / 接口 / 路由 / null |
| 交易术语相同 | 涨停、连板、晋级率、核按钮、断板、封单、炸板、接力、回流、埋伏、分歧、退潮 |
| 卡片可省略主语 | 「可买 2 只」可以；但不能写成「pool_call 命中 2 只」 |
| 判断词可追溯 | 卡面出现的判断（如「埋伏就绪」），终端要能找到同一个词 |
